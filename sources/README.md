โฟลเดอร์นี้เก็บไฟล์เนื้อหาอ้างอิงสำหรับ roots_voc และ archaic_voc รองรับ 2 รูปแบบ:

## 1) ไฟล์ .txt (ข้อความดิบ)
- ใช้กับนิยาย/บทความ/เนื้อเรื่องที่เป็นข้อความต่อเนื่องธรรมดา
- เวลารัน workflow ถ้าไม่ระบุ source_file ระบบจะสุ่มไฟล์ + สุ่มตัดช่วงข้อความ (4000 ตัวอักษร) ให้เอง
- คำแปลไทยในกรณีนี้ AI จะเป็นคนแปล/วิเคราะห์เอง

## 2) ไฟล์ .json (ตารางคู่คำแปลทางการ)
- ใช้กับข้อมูลที่มีคำแปลไทย "ทางการ" กำกับอยู่แล้ว (เช่น ข้อความในเกมที่แปลไทยแบบทางการ) เพื่อไม่ต้องให้ AI แปลเอง
- โครงสร้างไฟล์: JSON array ของ object แต่ละตัวมี key "en" (ข้อความอังกฤษ) และ "th" (คำแปลไทยทางการ) เท่านั้น เช่น:
  [{"en": "A ring that grants strength.", "th": "แหวนที่มอบพลัง"}, {"en": "...", "th": "..."}]
- เวลารัน workflow ระบบจะสุ่มหยิบหลายแถวจากไฟล์นี้มาให้ AI เลือกคำ แล้ว "บังคับ" ให้ใช้คำแปลไทยที่ให้มาเป็นฐานอ้างอิง ห้ามแปลขึ้นใหม่เอง (ดู archaic_voc's ฟิลด์ "thai"/"example_thai" จะดึงจากคำแปลทางการโดยตรง)
- ไฟล์ปัจจุบัน: elden_ring.json (คู่ EN/TH จากข้อความในเกม Elden Ring รวม DLC ทั้งสอง ~3,600 คู่)

## วิธีใช้ทั่วไป
- อัปโหลดไฟล์เข้ามาในโฟลเดอร์นี้ได้เรื่อยๆ ตั้งชื่อไฟล์อะไรก็ได้ (ลงท้าย .txt หรือ .json)
- ถ้าอยากบังคับให้ใช้ไฟล์ใดไฟล์หนึ่ง ให้พิมพ์ชื่อไฟล์เป๊ะๆ ในช่อง source_file ตอนกด Run workflow (เช่น elden_ring.json)
- ไฟล์ README.md นี้จะไม่ถูกใช้เป็นแหล่งอ้างอิง เพราะสคริปต์มองหาเฉพาะไฟล์ที่ลงท้ายด้วย .txt/.json
- target "general_voc" ไม่ใช้ไฟล์ source ใดๆ เลย (AI คิดคำศัพท์ CEFR เองทั้งหมด)
