โฟลเดอร์นี้เก็บไฟล์ .txt ที่เป็นเนื้อหาอ้างอิง (บทความ, นิยาย, เนื้อเรื่องเกม, คำอธิบายต่างๆ)

วิธีใช้:
1. อัปโหลดไฟล์ .txt เข้ามาในโฟลเดอร์นี้ได้เรื่อยๆ (ตั้งชื่อไฟล์อะไรก็ได้ เช่น dune.txt, the-witcher-lore.txt)
2. เวลารัน workflow "Generate Vocab via Claude" ถ้าไม่ระบุชื่อไฟล์ใน source_file ระบบจะสุ่มเลือกไฟล์ + สุ่มตัดช่วงข้อความในไฟล์นั้นให้เอง
3. ถ้าอยากบังคับให้ใช้ไฟล์ใดไฟล์หนึ่ง ให้พิมพ์ชื่อไฟล์เป๊ะๆ ในช่อง source_file ตอนกด Run workflow (เช่น dune.txt)

ไฟล์นี้ (README.txt) จะไม่ถูกใช้เป็นแหล่งอ้างอิง เพราะสคริปต์มองหาเฉพาะไฟล์ที่ลงท้ายด้วย .txt ที่ไม่ใช่ตัวมันเอง — แต่เพื่อความชัวร์ แนะนำให้ลบไฟล์นี้ทิ้งทันทีที่อัปโหลดไฟล์เนื้อหาจริงไฟล์แรกเข้ามาแล้ว
